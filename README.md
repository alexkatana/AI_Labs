## Запуск

1. Установить Python 3.12 или совместимую версию.
2. В корне репозитория выполнить `python -m pip install -r requirements.txt`.
3. Выполнить `python -m jupyterlab` и открыть нужный ноутбук из `src/`.
4. Запустить ячейки по порядку. ЛР №2 использует локальный CSV, доступ к сети не требуется.

Источник варианта вина: https://www.kaggle.com/datasets/uciml/red-wine-quality-cortez-et-al-2009 . Включённый CSV взят из предоставленного преподавателем архива. Его SHA-256 выводится в первой ячейке ЛР №2.
