## Фактические результаты

ЛР №3: по 3-fold CV macro-F1 выбран **RandomForest**. Test Accuracy **0.5478**, macro-F1 **0.3106**, macro ROC-AUC OVR **0.7755**. Перед разбиением удалено 240 точных повторов. Редкие оценки распознаются плохо; разрыв train/test отражён в выводах.

ЛР №4: по минимальному val-loss выбран **Hidden3_Adam**, эпоха **35**. Test Accuracy **0.6287**, macro-F1 **0.3079**. У глубокой сети поздние эпохи переобучаются, поэтому сохранена лучшая версия по validation. Часть внешнего train выделена под validation; объём фактического обучения отличается от №3.

ЛР №5: обучена новая голова **предобученной MobileNetV2**, backbone заморожен. 6495 изображений после удаления 4 RGB-повторов, train/val — 5196/1299. Validation Accuracy **0.8922**, macro-F1 **0.8921**. Сохранённый полный чекпойнт независимо загружен и проверен на всей validation: Accuracy совпала. Для ускорения CPU извлечены признаки чистого train и одной аугментированной версии каждого объекта; это не полное дообучение backbone и не новые аугментации каждую эпоху.

## Запуск

1. Установите Python (выполнение проверено на версии из `artifacts/tested_versions.json`).
2. В корне проекта: `python -m pip install -r requirements.txt`.
3. Запустите `python -m jupyterlab` и откройте ноутбук из `src/`.
4. Запускайте ячейки по порядку. №1–4 не требуют загрузки данных из интернета.

Для переобучения №5 выполните `python download_butterflies.py` или положите скачанный с Kaggle архив под именем `data/butterfly.zip`. Можно задать переменную окружения `BUTTERFLY_ZIP` с абсолютным путём к архиву. Ноутбук также умеет скачать архив автоматически. Предобученные веса ImageNet скачиваются torchvision при первом запуске. После этого они кешируются. Для чтения сохранённых результатов и графиков данные и обучение повторять не нужно.

CPU достаточно для этих настроек; GPU необязателен. В №5 загрузчики используют num_workers=0, что подходит и для Windows. Изображения лежат внутри ZIP и не требуют ручного распаковывания. Полный ZIP около 237 МБ не включён в репозиторий; все параметры, разбиения, модели и результаты включены.

## Ограничения оценки

- Вино: шесть наблюдаемых классов 3–8, сильный дисбаланс. Accuracy сама по себе недостаточна.
- №3: параметры и семья выбраны по CV только внутри train; test не использован для повторной настройки.
- №4: validation выбирает эпоху и модель. Test-loss по эпохам выводится по заданию, но не участвует в выборе.
- №5: официальный Kaggle test не размечен. Отложенная validation участвует в выборе эпохи, поэтому отдельной независимой тестовой оценки нет.
- Хеши исключают точные RGB-дубликаты, но не все визуально похожие изображения.
- ROC-AUC близкий к 1 не означает почти 100% правильных многоклассовых ответов.
- Фиксированный seed улучшает воспроизводимость, но разные версии библиотек/устройства могут немного менять результаты.
